Monad Metropolis · Track 04 · Judge access

Try Merit in ~5 minutes.

Everything below runs on the live deployment — nothing to install. The address bar shows the real domain on every page.

Open the product See the landing On-chain proof

1 · "Login" — there's no account to create

Merit is open and read-only for judges. You don't need to sign up.
  1. Top-right, click Connect → a wallet-style modal opens.
  2. No test credentials exist to leak — there is no password database. Pick either:
    • Click Connect wallet → since the demo has no browser wallet, it returns Read-only explore mode (no wallet present) (honest — no wallet is faked).
    • Or type any handle (e.g. judge) + any password → Sign in → shows Signed in as judge.
The whole product works without connecting anything — the modal is presentation only. The real cryptographic action is the passkey payment in step 3.

2 · Browse the reputation ledger

On /app, scroll to Verified agents (4 agents sorted by settled credibility: Frax Data Oracle $245, Vault Guard $90, Rebalance Bot $15, comms-agent $0). Click one to see its settled receipt trail (each row carries a verified · P256 or unverified chip), Copy proof command, and the Bound authority mandate it earned.

3 · Run a real verified payment

On an agent page, in Hire & settle:
  1. Leave the amount at $5 (any value works).
  2. Click Pay via x402 & receive receipt.
  3. Watch it live: your browser makes a P-256 passkey → a server-issued challenge → the signature is verified against Monad's native P-256 precompile (0x0100) → a verified receipt lands and the score updates.
Honest caveat: this deployment runs in demo mode (no executor key), so the receipt lands on the labelled demo ledger, not a broadcast tx. The passkey check against 0x0100 is real. With an executor key set, the same click broadcasts a real recordReceipt() tx.

4 · See authority enforced on-chain

  • On the agent page click Try escalate to HIGH tier → BLOCKED (can't spend past the earned tier — the Bankr fix).
  • Open /proof.html — live reads from the deployed contract: score $71 → cap $10; the allowed under-cap transfer that executed on-chain (tx 0xa511…dd12); the over-cap transfer that reverts: GuardedWallet: exceeds per-transaction cap.
